# ASL Sign Coach

Reconstruction of the visible ASL Sign Coach path: 24 short lessons, an eight-lesson beginner tier, a weekly activity view, progress stored in localStorage, alphabet and number practice, and an optional camera preview for signing-space setup. The camera stays in the browser and is not used to judge correctness. Links point learners to ASL University visual references for reliable sign models.

No usable source was found in the matching `AWEMISSIONS/ASL-Sign-Coach` repository; this app was rebuilt from the live experience. Later course content is a concise practice outline, not a recovery of the original lesson text.
